# CS350 - Database Project

## PawCare Management System

**Database Design and Implementation Project | CS350 - Introduction to Databases**

A database design and implementation project featuring Entity-Relationship Diagram (ERD) modeling, normalization up to Third Normal Form (3NF), SQL table creation, and query execution for a veterinary clinic management system.

---

## 1. Project Overview

**PawCare Management System** is a database project developed for the **CS350 - Introduction to Databases** course.

The system is designed to help a veterinary clinic manage its records efficiently by replacing manual paperwork and spreadsheets with a structured relational database.

## 3. Project Objectives

The main objectives of this project are:

1. Analyze business requirements.
2. Identify entities, attributes, and relationships.
3. Design an Entity-Relationship Diagram (ERD).
4. Convert the ERD into relational schemas.
5. Apply database normalization (1NF, 2NF, and 3NF).
6. Implement the database using SQL.
7. Populate tables with sample data.
8. Execute and test SQL queries.

## 4. System Features

The PawCare Management System provides the following features:

- **Owner Management:** Manage pet owners and their contact information.
- **Pet Registration:** Register pets and store their information.
- **Veterinarian Management:** Manage veterinarians and their specializations.
- **Appointment Scheduling:** Schedule and track appointments.
- **Medicine Inventory:** Store medicine inventory information.
- **Prescription Management:** Record prescriptions issued during appointments.
- **Reporting:** Generate reports using SQL queries.

## 8. Project Task Distribution

To ensure equal contribution among all team members, the project tasks were divided into four sections.

### Member 1 - Parts A & B

**Assigned Tasks:**
- Part A: Entity Types, Attributes, and Keys
- Part B: Relationships and Cardinalities

**Responsibilities:**
- Identify entities, attributes, and primary keys.
- Classify attributes based on their types.
- Define relationships between entities.
- Determine cardinalities and participation constraints.

### Member 2 - Parts C & D

**Assigned Tasks:**
- Part C: ERD Design
- Part D: Schemas Before Normalization

**Responsibilities:**
- Create the complete Entity-Relationship Diagram (ERD).
- Represent entities, attributes, and relationships.
- Map the ERD into relational schemas before normalization.

### Member 3 - Parts E & F

**Assigned Tasks:**
- Part E: Schemas After Normalization
- Part F: Create SQL Tables

**Responsibilities:**
- Apply normalization techniques (1NF, 2NF, and 3NF).
- Prepare the normalized relational schemas.
- Write SQL CREATE TABLE statements.
- Implement primary keys, foreign keys, and constraints.

### Member 4 - Parts G & H

**Assigned Tasks:**
- Part G: Populate Tables
- Part H: Sample Queries Execution

**Responsibilities:**
- Insert sample data into all database tables.
- Write and execute SQL queries.
- Test query execution and verify results.
- Capture and document query results.
