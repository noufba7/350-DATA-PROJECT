# 350-DATA-PROJECT
Database design and implementation project for CS350, featuring ERD modeling, normalization (up to 3NF), SQL table creation, and query execution for a veterinary clinic management system

PawCare Management System
Overview
PawCare Management System is a database project developed for the CS350 - Introduction to Databases course. The system is designed to help a veterinary clinic manage its records efficiently by replacing manual paperwork and spreadsheets with a structured relational database.

Project Objectives
Analyze business requirements.
Identify entities, attributes, and relationships.
Design an Entity-Relationship Diagram (ERD).
Convert the ERD into relational schemas.
Apply database normalization (1NF, 2NF, and 3NF).
Implement the database using SQL.
Populate tables with sample data.
Execute and test SQL queries.
System Features
Manage pet owners and their contact information.
Register pets and store their information.
Manage veterinarians and their specializations.
Schedule and track appointments.
Store medicine inventory information.
Record prescriptions issued during appointments.
Generate reports using SQL queries.

Project Task Distribution
To ensure equal contribution among all team members, the project tasks were divided as follows:

Member 1
Entity Types, Attributes, and Keys (Part A)
Relationships and Cardinalities (Part B)
Responsibilities:

Identifying entities, attributes, primary keys, and attribute classifications.
Defining relationships, cardinalities, and participation constraints.
Member 2
ERD Design (Part C)
Schemas Before Normalization (Part D)
Responsibilities:

Creating the complete Entity-Relationship Diagram (ERD).
Mapping the ERD into relational schemas before normalization.
Member 3
Schemas After Normalization (Part E)
Create SQL Tables (Part F)
Responsibilities:

Applying normalization techniques (1NF, 2NF, and 3NF).
Writing SQL CREATE TABLE statements with constraints and relationships.
Member 4
Populate Tables (Part G)
Sample Queries Execution (Part H)
Responsibilities:

Inserting sample data into all tables.
Writing and executing SQL queries.
Capturing and documenting query results.
Contribution Summary
Each team member was responsible for two major project sections, ensuring balanced workload distribution and collaborative completion of the database design and implementation process.
